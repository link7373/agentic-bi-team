> Created by Colin Beck — https://www.linkedin.com/in/beckcolin/

> Everything the team has produced for humans outside it — decks, documents,
> workbooks. Owned by `insights-communicator`; produced by `/make-deliverable`.
> Check here before building: last quarter's board deck is the right template for
> this quarter's.

Each deliverable lives in `deliverables/YYYY-MM-DD-short-slug/` with:

- the artifact itself (`.pptx` / `.docx` / `.xlsx` / `.md`) — rendered blobs are
  gitignored by file type
- `SOURCES.md` — every figure in the deliverable mapped to the query or analysis
  that produced it. **No number ships without a row here.**
